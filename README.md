## 🔎 What is this?

A practical **OSINT & digital investigation playbook** focused on finding, connecting and verifying publicly available intelligence.

Not just:

```text
Tool → Command → Result
````

Instead:

```text
LEAD
 ↓
DISCOVER
 ↓
PIVOT
 ↓
CORRELATE
 ↓
VERIFY
 ↓
DOCUMENT
```

> **Tools produce results. Investigators produce intelligence.**

# 📚 Playbook

### 👤 Identity & Username

`01 Username OSINT` · `02 Sherlock` · `03 Maigret`

Discover public profiles and investigate username reuse across platforms.

### 🌐 Search & Social

`04 Search Engines` · `05 Social Media OSINT` · `07 Search Engines OSINT`

Search smarter using operators, pivots, context and independent sources.

### 🖼️ Image Intelligence

`06 Reverse Image OSINT`

```text
TinEye  •  Google Lens  •  Bing Visual Search
```

Find public matches, historical appearances and visual connections.

### 🌍 Infrastructure

`08 Domain & DNS` · `09 WHOIS/RDAP` · `10 Certificate Transparency`

Move from:

```text
DOMAIN → DNS → SUBDOMAIN → CERTIFICATE → INFRASTRUCTURE
```

### 📄 Documents & Metadata

`11 Public Documents` · `12 Metadata`

Extract useful investigative context from publicly available files and images.

### 📧 Email Intelligence

`15 Email OSINT`

Treat an email as an **investigation pivot**, not an endpoint.

# 🧠 Investigator Rules

```text
01  A result is a lead.
02  A lead is not automatically evidence.
03  Correlation is not proof.

06  Preserve the evidence trail.
```
